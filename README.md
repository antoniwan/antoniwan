## What I'm Building

- **[`notes`](https://github.com/antoniwan/notes)** — Personal blog engine. Legible, fast, opinionated.
- **[`links-forest`](https://github.com/antoniwan/links-forest)** — A themeable LinkTree alternative (Astro + Tailwind).
- **[`my-prompt-library`](https://github.com/antoniwan/my-prompt-library)** — Prompts I actually use. Curated, tested, alive.
- **[`SoundCraft`](https://github.com/antoniwan/SoundCraft)** — Self-hosted audio system for music production.
- **[`bsky_follower`](https://github.com/antoniwan/bsky_follower)** — Go tool for organic Bluesky growth by topic.
- **[`org-manager-api-map-prototype`](https://github.com/antoniwan/org-manager-api-map-prototype)** — Public API prototype with map-based org data UI.
- 🧪 **`mobile-first turborepo`** — A monorepo incubating multiple apps under one architecture. Expo + React Native, tRPC, Hono on Cloudflare Workers, Turso (edge SQLite), Drizzle ORM, NativeWind, Zustand + TanStack Query. Modular monolith backend designed for extraction. COPPA-aware. Privacy-first. Scale-to-zero infra.
- 🧪 **`cooperative platform engine`** — Trust-weighted identity, real-time reputation, profit-sharing ledger. Next.js + Service Workers + IndexedDB. Offline-first. Designed for communities, not corporations.
- 🧪 **`offline profile system`** — Hash-encoded shareable profiles. No database. Exports to markdown, text, PDF. Doubles as structured context for AI agents. Next.js + localStorage + optional cloud sync.
- 🧪 **`human systems toolkit`** — A constellation of micro-products in R&D: structured journaling with pattern detection, AI conversation export analysis, heritage recipe systems, digital legacy architecture, and async emotional processing frameworks. All built on the same monorepo spine.
